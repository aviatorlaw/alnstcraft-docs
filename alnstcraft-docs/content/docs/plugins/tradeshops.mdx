We use **QuickShop-Hikari** to manage tradeshops. The currency of the server is **$**.

### Creating a Shop
1. Place a chest.
2. Hold the item you want to sell in your hand.
3. Look at the chest and type `/qs create {price}`.

### Removing a Shop
To delete a tradeshop, face a tradeshop you own and run `/qs remove`.
