We use **QuickShop-Hikari** to manage tradeshops[cite: 3]. The currency of the server is **$**[cite: 3].

### Creating a Shop
1. Place a chest[cite: 3].
2. Hold the item you want to sell in your hand[cite: 3].
3. Look at the chest and type `/qs create {price}`[cite: 3].

### Removing a Shop
To delete a tradeshop, face a tradeshop you own and run `/qs remove`[cite: 3].
