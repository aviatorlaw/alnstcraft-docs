These rules apply to the Minecraft server specifically, but the general Discord server rules apply server-wide[cite: 3].

### Core Rules

1. **Be Respectful:** Always be respectful in situations, and try to avoid causing drama with other players[cite: 3]. We do not tolerate racism, sexism, homophobia, etc[cite: 3].
2. **No Cheating:** Using a modified client designed to hack or cheat is not tolerated and will result in instant removal[cite: 3].
3. **No Stealing:** Stealing from other bases, whether claimed or unclaimed, is not allowed[cite: 3].
4. **Respect Claims:** If you want to build or mine near another player's claim, you must ask them[cite: 3].
5. **No Exploiting Bugs:** Bugs that are game-breaking or give an unfair advantage over other players (like dupers) are not allowed[cite: 3]. However, bugs such as bedrock breakers to access the Nether roof are allowed[cite: 3]. If you are unsure, open a ticket[cite: 3].
6. **No Lag Machines:** Creating lag machines intentionally will result in a ban[cite: 3].
7. **Staff Discretion:** Any dispute will be judged by a mod and their ruling is **final**[cite: 3].
