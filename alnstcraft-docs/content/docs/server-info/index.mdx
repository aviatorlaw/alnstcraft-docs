## Connection Info

* **Java IP**: `mc.alnstcord.xyz`
* **Bedrock Port**: `25599`
* **Version**: Native for 1.21+, with backwards compatibility for 1.8+

## World Boundaries

<Callout type="info" icon={<Compass className="w-4 h-4" />}>
  **Overworld Border**: The Overworld border is currently set to **10,000 blocks** out in each direction from spawn ($x=\pm10,000$, $z=\pm10,000$).
</Callout>

## Server Requirements

To access ALNSTCRAFT, you must hold at least one of the required roles in the Discord server:
* `@VIVIs`
* `@MC Access`
* `@MC Tester`
* `@Moderators`
