These rules apply to the Minecraft server specifically, but the general Discord server rules apply server-wide.

### Core Rules

1. **Be Respectful:** Always be respectful in situations, and try to avoid causing drama with other players. We do not tolerate racism, sexism, homophobia, etc.
2. **No Cheating:** Using a modified client designed to hack or cheat is not tolerated and will result in instant removal.
3. **No Stealing:** Stealing from other bases, whether claimed or unclaimed, is not allowed.
4. **Respect Claims:** If you want to build or mine near another player's claim, you must ask them.
5. **No Exploiting Bugs:** Bugs that are game-breaking or give an unfair advantage over other players (like dupers) are not allowed. However, bugs such as bedrock breakers to access the Nether roof are allowed. If you are unsure, open a ticket.
6. **No Lag Machines:** Creating lag machines intentionally will result in a ban.
7. **Staff Discretion:** Any dispute will be judged by a mod and their ruling is **final**.
