title: Account Linking
description: How to whitelist yourself using DiscordSRV
icon: link
---

ALNSTCRAFT uses **DiscordSRV** to manage who can and cannot join the server. Follow these steps to link your account:

1. **Join the Server:** Join the Minecraft server using the IP `mc.alnstcord.xyz` (and port `25599` for Bedrock).
2. **Get your Code:** You will be disconnected and given a unique code on your screen. Remember this code.
3. **Message the Bot:** Send a direct message to the server bot with the code you were given. **Only** send the code. The bot will confirm that your account is linked.
4. **Rejoin:** Rejoin the server. You should now be able to play!

<Callout type="info">
  If you run into any issues with linking your account, open a support ticket in the Discord server.
</Callout>
