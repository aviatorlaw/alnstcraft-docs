ALNSTCRAFT uses **DiscordSRV** to manage who can and cannot join the server. Follow these steps to link your account:

<div className="fd-steps [&_h3]:fd-step">

### Join the Server

Join the Minecraft server using the IP `mc.alnstcord.xyz` (and port `25599` for Bedrock).

### Get your Code

You will be disconnected and given a unique code on your screen. Remember this code.

### Message the Bot

Send a direct message to the server bot with the code you were given. **Only** send the code. The bot will confirm that your account is linked.

### Rejoin

Rejoin the server. You should now be able to play!

</div>
