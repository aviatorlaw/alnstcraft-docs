## Connection Info

* **IP:** `mc.alnstcord.xyz`
* **Bedrock Port:** `25599`
* **Version:** Native for 26.2, with support for 1.8+

## Requirements

To join ALNSTCRAFT, your device must meet the standard system requirements to run Minecraft (Java or Bedrock). You must also have one of the required Discord roles.
